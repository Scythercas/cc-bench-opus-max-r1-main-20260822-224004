# タスク管理アプリ

素のHTML / CSS / JavaScript だけで作った、シングルページのタスク管理（TODO）アプリです。
フレームワーク・ライブラリ・CDN・Webフォントを一切使わず、**外部への通信を行いません**。
ビルド工程も不要で、`index.html` をブラウザで開けばそのまま動きます。
データはブラウザの `localStorage` に保存されるため、リロードしても内容が残ります。

## 機能一覧

| ID | 機能 |
|---|---|
| F1 | タスクを追加できる。タイトルが空白のみの場合は追加されない（全角スペースのみも不可） |
| F2 | タスク一覧が表示される |
| F3 | 各タスクの完了／未完了をトグルできる |
| F4 | 各タスクを削除できる |
| F5 | 各タスクのタイトルを編集できる |
| F6 | タスクに期限日を設定できる（未設定も可） |
| F7 | タスクに優先度（高 / 中 / 低）を設定できる。既定は「中」 |
| F8 | 「すべて / 未完了 / 完了済み」で絞り込める |
| F9 | 「作成順 / 期限昇順 / 優先度順」で並べ替えられる |
| F10 | 未完了タスクの残り件数が表示される |
| F11 | 内容が `localStorage` に保存され、リロード後も復元される |
| F12 | 完了済みタスクを一括削除できる |

### 操作方法

- **追加**: タイトルを入力して `Enter`、または「追加」ボタン。期限日と優先度は任意。
- **完了**: 各行のチェックボックス（`Space` キーでも切り替え可）。
- **編集**: 「編集」ボタン → 行内の入力欄を書き換え → `Enter` か「保存」ボタン、または欄の外へフォーカスを移すと確定。`Escape` で取り消し。
- **削除**: 各行の「削除」ボタン。
- **絞り込み / 並べ替え**: 一覧の上にあるボタンとセレクトで切り替え。
- **完了済みを一括削除**: 一覧の下の「完了済みを削除」ボタン。

### アクセシビリティ

- すべての操作をキーボードだけで行えます（`Tab` で移動、`Enter` / `Space` で実行）。
- 各コントロールに `label` または `aria-label` を付け、絞り込みボタンには `aria-pressed`、残り件数には `role="status"` を設定しています。
- 一覧を再描画してもフォーカス位置を失わないようにしています。
- `prefers-color-scheme: dark` に対応（OSの設定に追従）。
- 幅375px（スマートフォン相当）でも横スクロールが発生しません。

## ローカルでの開き方

依存パッケージのインストールもビルドも不要です。

1. このリポジトリを取得します。

   ```sh
   git clone https://github.com/Scythercas/cc-bench-opus-max-r1-main-20260822-224004.git
   cd cc-bench-opus-max-r1-main-20260822-224004
   ```

2. `index.html` をブラウザで開きます（ファイルをダブルクリックするだけでも動きます）。

   ```sh
   # macOS
   open index.html
   # Windows
   start index.html
   # Linux
   xdg-open index.html
   ```

`file://` で直接開いた場合でも `localStorage` への保存は動作します。
ローカルサーバー経由で確認したい場合は、任意の静的サーバー（例: `python -m http.server`）でこのディレクトリを配信してください。

## ファイル構成

| ファイル | 役割 |

| `index.html` | 画面の構造（1行分のマークアップは `<template>` に定義） |

## 保存データについて

`localStorage` のキー `task-manager.tasks.v1` に、次の形の配列をJSONで保存します。

```json
[{ "id": "m1abcd-xy12", "title": "牛乳を買う", "done": false, "due": "2026-09-01", "priority": "high" }]
```

読み込み時に型を検証し、壊れた値や未知の優先度は既定値に補正します。
ブラウザの設定で `localStorage` が使えない場合でも、保存を諦めるだけでアプリはそのまま動作します。
